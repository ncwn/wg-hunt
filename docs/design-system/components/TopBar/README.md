# TopBar

The top of every page: the page title, an optional one-line summary, the hunting status, and the page's own tools.

- Props: `title`, `subtitle` ("6 new rooms since you last looked"), and `children` for the page's tools at the right (the Offers sort and Mark all seen). The [StatusPill](../StatusPill/README.md) and its detail come from the hunt's status, not from props.
- The subtitle is the one sentence the seeker most wants on that page; leave it out rather than fill it.
