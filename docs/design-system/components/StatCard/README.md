# StatCard

A pastel card with one count, what it counts, and a short note — the Overview's "Your hunt" row.

- Props: `tone` (`lavender`, `mint` or `butter`, by [what it counts](../../README.md#colour)), `label` at the top, `value` at the foot, `note` ("4 new") beside the figure, `onClick` to make the whole card a button that opens what it counts (Shortlisted opens the Shortlisted view of Offers).
- Three or four in a row, never more. Each counts something the seeker acts on.
