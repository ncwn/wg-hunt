# Icon

The wg-hunt icon set: 24px line icons with a 1.8px round stroke, drawn in `currentColor`, always hidden from screen readers: the words beside it, or the button's label, carry the meaning.

- `name` is one of home, offers, star, radar, user, settings, logout, calendar, check, x, chevronDown, chevronRight, chevronLeft, plus, trash, refresh, external, pause, play, message, house, expand, sparkle. `size` in px (default 20).
- [Iconography](../../README.md#iconography) says where icons go.
- Map: home Overview, offers Offers, radar Searches, user Profile, settings Settings, logout Sign out, star the shortlist mark, message Mark contacted, x closing and Not for me, refresh Recheck, Check now and undoing Not for me, sparkle Re-analyse, external leaving for wg-gesucht, pause/play the StatusCard action, calendar a date field, chevronLeft/chevronRight stepping months and photos, expand a photo full size, plus adding a Search or a Place, trash removing a Place, house every table row's thumbnail and the card's stand-in when there are no photos, check a ticked choice and Contacted, chevronDown a fold, a chip with a quote and a select's trigger.
