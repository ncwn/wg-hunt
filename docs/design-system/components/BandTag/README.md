# BandTag

The verdict on an offer — Match, Near match, Warned or Hidden — as a small tinted tag with one word.

- `band`: `match` (`match` on `mint`), `near` (`near` on `butter`), `warned` (`warned` on `rose`), `hidden` (`hidden` on `surface-sunken`). Children override the word, as the request log's outcome tags ("Bot check") do.
- One tag per offer, in the Fit column or beside the card's title.
