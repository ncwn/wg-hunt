# Logos

- `wg-hunt-mark.svg` — the app [mark](../../README.md#logo) in ink `#15171c` (`brand-ink`) on the butter tile `#f5e9c4` (`brand`). The sign-in and "Can't reach wg-hunt" screens and the browser tab use it.
- `wg-hunt-glyph.svg` — the bare house-and-lens in ink `#15171c`, with the lens cut out. For favicons and app icons that supply their own background; never place it on `rail` (ink on near-black disappears).

There is no wordmark file: the word is set live.
